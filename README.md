The order I recommend

Don't try to build everything simultaneously.

Phase 1 — Brand Foundation

Website + positioning

Phase 2 — Sales Assets

Pitch deck + company profile + proposal template

Phase 3 — Sales Infrastructure

ICP + target-account database + CRM + outreach scripts

Phase 4 — Team

BDE + Marketing/Growth

Phase 5 — Launch

50 prospects/day + LinkedIn + email

Phase 6 — Optimize

Measure:

Contacts → Replies → Meetings → Qualified Opportunities → Proposals → Wins

Most important

Before we hire heavily, YESP itself needs to look like the kind of company we're asking enterprise clients to trust.
